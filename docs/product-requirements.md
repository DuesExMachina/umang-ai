# UMANG AI

## Problem

UMANG provides access to a large number of government
services and schemes.

However, a novice citizen may ask:

"Which government schemes am I eligible for?"

The existing conversational experience may not be able
to determine eligibility and instead directs the user
to explore the service catalog themselves.

This creates a discovery problem.

## Goal

Allow citizens to describe their situation in natural
language and receive a personalized list of potentially
relevant government schemes/services.

## MVP

The system should:

1. Accept natural-language user queries.
2. Extract relevant user attributes.
3. Identify missing information.
4. Ask only necessary follow-up questions.
5. Evaluate eligibility against curated scheme rules.
6. Rank matching schemes.
7. Explain why each scheme matched.
8. Explain missing requirements.
9. Show required documents.
10. Provide next steps.

## Non-goals

- Real government submissions
- Private government APIs
- Complete UMANG dataset
- Real citizen identity verification
- Real financial transactions
